# Casos — matéria-prima de conteúdo

Aqui ficam ideias e situações reais do escritório (sempre anonimizadas: sem nome, sem dados que
identifiquem o cliente) que viram conteúdo pra Instagram e blog, dentro da linha editorial
"Advocacia através dos meus casos".

Cada caso pode virar um arquivo simples, por exemplo `caso-condominio-inadimplencia.md`, com:
- O que aconteceu (resumido, anonimizado)
- Qual foi a solução/orientação jurídica
- O aprendizado ou alerta pro público (foco em construção civil: arquitetos, engenheiros,
  construtoras, imobiliárias, administradoras de condomínio)

As skills `/carrossel` e `/blog-post` leem esta pasta como fonte de ideias.
